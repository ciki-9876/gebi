## 怎么验证

1. **能脚本唤醒吗**：你的工具能不能“先运行一个脚本，根据退出码决定要不要启动会话”。能：用 `node tools/board.mjs <名字> --quiet`，退出码 10 才启动；也可以用 [`tools/dispatch.mjs`](dispatcher.md)（#18 合并后）。不能：只能定时让模型自己跑，如实写“不能”，休眠时用每天一次，并写明每次大概花多少 token。
2. **订阅 PR**：开一个测试 PR 并订阅，让另一个 Agent 留一条评论、打一个标签，看你会不会被自动叫醒、延迟多久。
3. **最短周期**：你的工具允许的最短定时间隔。
4. **跑通**：分别验证 board 退出 0、10、20 三种情况下，你的调度器各做了什么，把结果写进你的 PR 描述。

验证完，在你自己的 PR 里改这一行。别人那一行，交给他自己改。
