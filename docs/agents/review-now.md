# 立即评审

自动指派和定时检查有延迟（最长一个检查周期）。**需要某个 PR 现在就被评审、合并时**，用这个办法，不用等轮询。

Agent 没有被推送的入口，不能“远程叫醒”：它只会在自己的工具里被运行时才动。所以“立即”的意思是：你把任务交给那个 Agent，让它的工具现在就跑一次。下面的命令帮你把这一步变成一条命令加一段现成的话。

## 一条命令

在仓库目录里（需要 `gh` 已登录）：

```bash
node tools/review-now.mjs <PR号> [评审者名字]
```

例如 `node tools/review-now.mjs 12 HomeGPT`。不写名字时，从登记表里挑作者以外、手上待办最少的 Agent。

它会做三件事：

1. 把 PR 指派给评审者：换掉原来的 `handoff:*`，打上 `handoff:<名字>`、`ready-for-review`、`urgent`。
2. 在 PR 上留一条说明，写明是加急、指派给了谁。
3. **打印一段话**，你直接发给那个 Agent 就行；同时给出能在终端里直接触发它的命令行写法。

只想看看会做什么，加 `--dry-run`，不会改动任何东西。

## 两种“现在就跑”

| 方式 | 怎么做 |
| --- | --- |
| 把话发给它 | 把命令打印的那段话粘贴到那个 Agent 的会话里。已经打开着它的窗口时最快 |
| 在终端里触发 | 如果它的工具有命令行模式（比如 `claude -p "…"`、`codex exec "…"`），在它自己克隆的目录里运行命令打印出来的那一行，不用打开窗口。命令名以你机器上装的版本为准 |

评审者那边做完会回复一句结果；通过且三项检查全绿后，由评审者合并，不需要你再动手。

## 什么时候用

- 一个 PR 卡着别的工作，等不起一个检查周期。
- 指派的 Agent 很久没响应，想换一个人：`node tools/review-now.mjs <PR号> <另一个名字>`。
- 大部分时候不需要：自动指派加定时检查够用，见 [`polling.md`](polling.md)。

## 不能做什么

- 不能绕过规则：作者不能评审自己的 PR，三项检查没绿也合并不了。命令会拒绝把作者指派成评审者。
- 不能叫醒没有在运行的 Agent。命令只能把任务写好、把话备好。
