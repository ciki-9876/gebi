# Button

实体键：有厚度的键帽，按下会下沉。所有按钮都是它。

- `.btn` 默认键，`.btn.primary` 主键（字和顶部灯带亮背光），`.btn.ghost` 没有键帽的文字键（取消、再看看），`.btn.danger` 字是红灯色。
- 尺寸：`.btn.sm` 32、默认 40、`.btn.lg` 48。键下方自带 `key-depth` 的外边距，按下时不挤动布局。
- 锁定状态（开关、当前模式）用 `aria-pressed="true"`：键停在按下位置。
- 一屏只有一颗主键。面板底部的主键放最左。
- 图标 16px，`currentColor`。

不要：两颗主键并排；给键帽换颜色表达状态（用灯和锁定位置）；按钮文字写“确定 / 取消”。
