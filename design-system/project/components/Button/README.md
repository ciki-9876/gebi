# Button

按钮：触发一个动作，文字直接写动作本身。

- `.btn` 次级（默认），`.btn.primary` 主操作，`.btn.ghost` 取消与“再看看”，`.btn.danger` 危险操作，`.btn.glass` 浮在 3D 画面上。
- 尺寸：`.btn.sm`（30px，列表与卡片里）、默认 38px、`.btn.lg`（46px，首页）。
- 一屏只有一个 `.primary`。面板底部的主按钮放最左。
- 禁用用 `disabled` 属性，样式自动降到 42% 不透明度。
- 图标放在文字后面（外链箭头）或前面（旋转、删除），16px，`currentColor`。

不要：两个主按钮并排；用颜色以外的方式区分不了的“危险”按钮；按钮文字写“确定 / 取消”这类不说明结果的词。
