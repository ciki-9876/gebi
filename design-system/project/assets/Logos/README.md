# Logos

标志是两栋房子，右边那间亮着灯：“你的隔壁有人在”。

- `gebi-mark.svg`：深色底用。主体房子描边 `fog-100`（即 `text-1`），邻居房子 `fog-300`（`text-2`），小窗填充 `glow-400`（`accent`，背光青）。墨色写死在文件里，因为 `<img>` 不能继承 CSS 颜色。
- 代码里直接用内联 SVG（`.mark`），颜色由 token 控制。
- 标志旁的字标“隔壁”用 `sans` 700。最小尺寸 20px；四周留白不少于标志宽度的四分之一。
- 不要给标志加渐变、描边以外的阴影，不要把小窗换成别的颜色。
