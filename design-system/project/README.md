隔壁是一个给写代码的人住的社区：每人在地球上有一间房，作品就是房间里的家具。界面的任务是让人看清“谁在、能去哪、能做什么”，然后把画面让给地球和房间。

## 概念：舷窗

你坐在一艘绕地球飞行的小飞船里。首页是一面舷窗，地球在窗外；界面长在舱壁上：上窗框是导航，下窗框是控制台。进了房间，舱壁收成一条顶框，房间里的游戏机、吧台、黑板和界面上的键是同一个世界里的实物。

三种材质贯穿所有界面，每个组件只属于其中一种：

| 材质 | 长什么样 | 用在哪里 |
| --- | --- | --- |
| **实体键** | 有厚度的深色键帽，底下露一截侧面；按下下沉 4px，侧面消失 | 所有按钮、模式切换、导览、筛选、标签页、色块、住户标签 |
| **凹槽小屏** | 凹进舱壁的深色屏，磷光字，可选扫描线 | 输入框、搜索槽、控制台小屏、轻提示、代码、读数、刻印标签 |
| **舱板** | 舱壁上的一块板，细颗粒表面，顶边一道高光，四周一圈暗缝 | 面板、作品窗口、物件库、名片、物件卡、数据条 |

没有毛玻璃：舱壁不透光。浮在 3D 画面上的东西要么是一块舱板，要么是一颗键。

## 背光：唯一的亮色

背光青 `accent` 是键帽背光的颜色，只给三种东西：

- **主键**：一屏一颗，键帽不变，字和顶部一条灯带亮起（`.btn.primary`、控制台的“回到我的房间”）。
- **你自己的房间**：地球上你的标签与标记、门牌数字、门牌上的小窗。
- **选中**：锁在按下位置的那颗键，字亮背光。

其余都是舱壁的中性色：`bg` → `surface-1`（舱壁）→ `surface-2`（凸起的分组）→ `surface-3`（键帽）→ `surface-4`（键帽高光）。层级靠材质和厚度表达，不靠颜色。

指示灯是状态的主要表达：绿灯 `success` 在线、已接入；粉灯 `heat` 通知、待上传；红灯 `danger` 错误；信息灯 `info` 说明与链接；熄灭 `led-off`。灯旁边总有字，不靠颜色单独表达状态。

## 首页：舷窗、轨道、控制台

- **舷窗**：画布铺满全屏，窗框用 `frame-top` `frame-side` `frame-bottom` 三个尺寸挖出一面 `r-window` 圆角玻璃。地球取景在窗内居中偏右，整颗可见。
- **轨道上的邻居动态**：动态不放卡片，而是挂在绕地球的一道轨道弧上，最新的在最上面。悬停一条动态，或者有新动态到达时，一根虚线从轨道连到地球上那户人家，那户亮起准星。这是首页唯一的记忆点。
- **窗上的标题**：贴在玻璃左下角，没有底。
- **控制台**：主键“回到我的房间”最大，右边是选址、物件流两颗竖键，然后是搜索槽（小屏里带实时昼夜读数），最右是“你的房间”小屏。
- **本周主题**：上窗框正中一条凹槽，十颗指示灯表示亮灯的房间数。

## 门牌：系统的标志元素

房间号永远用门牌显示：凹进舱壁的一块小牌，等宽数字亮背光，左边一扇亮着的小窗。顶框、住户面板、名片、分享卡片和 3D 房门上的门牌是同一个样子。

## 颜色

| 角色 | token | 用在哪里 |
| --- | --- | --- |
| 背光 | `accent` `accent-text` `accent-soft` `accent-line` `accent-glow` | 主键、你的房间、门牌、选中的键 |
| 小屏 | `screen` `screen-text` `screen-bright` `screen-dim` `scanline` | 输入框、搜索槽、控制台小屏、轻提示、代码 |
| 信息 | `info` `info-soft` `info-line` | 链接、坐标、SDK、权限与分享说明 |
| 在线 | `success` `success-soft` | 在线灯、“已接入 SDK”、新邻居 |
| 热度 | `heat` `heat-soft` `heat-line` | 通知红点、改编标签、待上传 |
| 危险 | `danger` `danger-soft` | 删除、错误文字 |

- 文字只用 `text-1`、`text-2`、`text-3`；小屏里用 `screen-*`。`text-3` 只放在 `bg` 与 `surface-1/2/3` 上，在这些底上都不低于 4.5:1。
- 背光色块上的文字用 `text-on-accent`。
- 组件里只用语义 token。`hull-*` `fog-*` `glow-*` `phos-*` 等原始色板只在 tokens 文件内部被引用。

## 拟物 token

| token | 作用 |
| --- | --- |
| `key-face` `key-face-hover` | 键帽顶面的渐变 |
| `key-shadow` `key-shadow-down` | 抬起与按下两种状态的整套阴影 |
| `key-edge` `key-depth` | 键帽侧面颜色与键程（4px） |
| `recess` | 凹进舱壁 |
| `plate-edge` | 舱板四周的暗缝、顶边高光和投影 |
| `grain` | 舱壁表面的细颗粒 |
| `legend-glow` | 背光字的光晕 |

按键的规则：抬起时用 `key-shadow` 并留出 `margin-bottom: var(--key-depth)`；按下或锁定时 `translateY(var(--key-depth))` 加 `key-shadow-down`，所以布局不会跳。

## 字体

- `sans`：拉丁字母和数字用圆润的 Nunito，中文回落思源黑体。圆体和注塑键帽是同一种手感。
- `mono`：JetBrains Mono，只用在小屏、门牌号、坐标、刻印标签和代码。
- 字重比一般界面重一档：键上的字 600，标题 700，大标题和门牌号 800。
- 首页主标题 `fs-4xl`（44px），面板标题 `fs-xl`（20px），界面默认 `fs-md`（13px）。

## 间距、圆角、尺寸

- 间距是 4 的倍数。键之间留 `sp-2` 到 `sp-4`，因为键有厚度，挤在一起会粘成一片。
- 圆角都比较圆，像注塑件：`r-xs` 刻印标签 → `r-sm` 小键 → `r-md` 键与小屏 → `r-lg` 大键与分组 → `r-xl` 面板与窗口 → `r-window` 舷窗。
- 控件高度：`h-sm` 32、`h-md` 40、`h-lg` 48，控制台主键 92。触屏可点区域不小于 `hit-min` 40。

## 动效

- `dur-press` 70ms：按键下沉，是整个系统最常出现的动作，要快、要干脆。
- `dur-1` 悬停、`dur-2` 出现、`dur-3` 面板与窗口。
- 轨道引线用虚线流动表示“正在连”，新动态到达时亮 4 秒。
- 尊重系统的“减少动态效果”设置。

## 文案

- 写用户能认出的东西：说“房间、门牌、物件、作品、邻居、口袋”。
- 键上写动作：“回到我的房间”“敲门进去”“选址入住”。轻提示说结果：“名片已保存”。
- 错误说清楚怎么办，不道歉。权限和限制照实说，并给出能做的事。
- 称呼用“你”。中文与英文、数字之间留一个空格。不用 emoji。

## 3D 场景与界面的边界

- 房间里的霓虹灯牌、粉笔黑板、作品屏幕、地球的光点与大气层有自己的美术，不受 token 约束。
- 叠在场景上的 HTML 界面必须用 token。画在 canvas 和 3D 里的界面元素（分享卡片、门牌、地球上你的标记、悬停准星、选址标记、选中圈）通过代码里的 `TK` 读取同一套 token。
- 房主作品自带的皮肤属于作品本身，不随设计系统变化。
