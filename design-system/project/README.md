隔壁是一个给写代码的人住的社区：每人在地球上有一间房，作品就是房间里的家具。界面的任务是让人看清“谁在、能去哪、能做什么”，然后退到 3D 画面后面。

## 概念：夜里的街区

界面是一条安静的冷色夜街，只有“有人在”的地方亮着暖色窗灯。

- 窗灯 `accent` 只给三种东西：**主操作**（敲门进去、保存名片）、**你自己的房间**（地球上你的标签、门牌）、**选中态**。一屏只亮一处主操作。
- 其余全部是冷色中性：`bg` → `surface-1` → `surface-2` → `surface-3` → `surface-4`，越往上越亮，用来表达层级，而不是靠阴影。
- 浮在 3D 画面上的条（顶栏、导览条、搜索框）用 `glass` 加 `blur`，让场景透过来；面板和弹窗用实色 `surface-1`。

## 门牌：系统的标志元素

房间号永远用门牌显示：`plate` 等宽数字、`accent-text` 颜色、`accent-line` 描边，左边一扇亮着的小窗（`accent` 填充加光晕）。顶栏、住户面板、名片、分享卡片和 3D 房门上的门牌是同一个样子。不要把房间号写成普通文字或彩色徽章。

## 颜色

| 角色 | token | 用在哪里 |
| --- | --- | --- |
| 窗灯 | `accent` `accent-text` `accent-soft` `accent-line` | 主按钮、你的房间、门牌、选中的分段与筛选 |
| 屏幕光 | `info` `info-soft` `info-line` | 链接、坐标、SDK、权限与分享说明块 |
| 在线 | `success` `success-soft` | 在线点、“已接入 SDK”、新邻居标签 |
| 热度 | `heat` `heat-soft` `heat-line` | 通知红点、改编标签、装修里的“待上传” |
| 危险 | `danger` `danger-soft` | 删除、错误文字、关闭按钮悬停 |

- 文字只用 `text-1`（正文、标题）、`text-2`（说明）、`text-3`（辅助、眉标、占位）。`text-3` 只放在 `bg` 与 `surface-1/2/3` 上，在这些底上都不低于 4.5:1。
- 窗灯色块上的文字用 `text-on-accent`，不用白色。
- 语义色不替代文字：每个状态同时有字（“等作者上传”“加载失败”），不靠颜色单独表达。
- 组件里只用语义 token。`ink-*` `fog-*` `lamp-*` 等原始色板只在 tokens 文件内部被引用。

## 字体

- 两个家族：`sans`（拉丁字母用 Schibsted Grotesk，中文回落思源黑体）和 `mono`（JetBrains Mono）。
- `mono` 只用于门牌号、坐标、主机名、眉标和代码，让“数据”一眼可辨。
- 字号只用阶梯里的值：界面默认 `ui`（13px），正文 `body`（14px），面板标题 `title-panel`（20px），首页主标题 `display-xl`（64px）。32px 以上的标题用 `letter-spacing` -0.02em。
- 眉标 `eyebrow`：11px 等宽、全大写、字距 0.08em、`text-3`。用来给分组命名，不用来装饰。

## 间距、圆角、尺寸

- 间距是 4 的倍数：`sp-2`（8px）同组控件之间，`sp-3`（12px）列表行内边距，`sp-4`（16px）卡片内边距与表单字段之间，`sp-5`（20px）面板左右内边距。
- 圆角按物体大小递增：`r-xs` 标签 → `r-sm` 小按钮与列表行 → `r-md` 按钮与输入框 → `r-lg` 卡片与浮条 → `r-xl` 面板与窗口；`r-pill` 只给分段控件、搜索框和筛选。
- 控件高度：`h-sm` 30、`h-md` 38、`h-lg` 46。触屏上可点区域不小于 `hit-min` 40。

## 层次与动效

- 描边优先：卡片用 `border-1`，控件用 `border-2`，悬停变 `border-3`。阴影只给真正浮起来的东西：`shadow-1` 轻提示，`shadow-2` 面板，`shadow-3` 作品窗口与弹窗。
- 动效时长：`dur-1` 120ms 悬停与按下，`dur-2` 200ms 出现与切换，`dur-3` 320ms 面板、窗口和滑块；进入用 `ease-out`。尊重系统的“减少动态效果”设置。
- 键盘焦点：2px `bg` 间隙加 2px `accent` 实线，所有可交互元素都有。

## 文案

- 写用户能认出的东西：说“房间、门牌、物件、作品、邻居、口袋”，不说“文档、实体、节点”。
- 按钮写动作：“敲门进去”“保存名片”“全部摆进我的房间”。完成后的轻提示说结果：“名片已保存”“已放进口袋：现在 3 件”。
- 错误说清楚怎么办：“链接需要以 https:// 开头。”不道歉，不含糊。
- 权限和限制照实说，并给出能做的事：“你现在是查看者：能逛、能试玩，收藏会放进这台设备上的口袋。”
- 称呼用“你”，房间的主人叫“房主”，来的人叫“访客”或“邻居”。中文与英文、数字之间留一个空格；引号用中文引号“”。不用感叹号堆情绪，不用 emoji。

## 图标

- 图标是内联 SVG，16 或 20 的视图框，1.5–1.8 的描边，`currentColor` 上色，跟随文字颜色。
- 标志是两栋房子，右边那间亮着灯：主体用 `text-1`，邻居用 `text-2`，小窗用 `accent`。见资源里的 Logos。
- 收藏按钮里的“☆”是遗留的文字字形，计划换成 SVG 图标，新代码不要再用字形当图标。

## 3D 场景与界面的边界

- 房间里的霓虹灯牌、粉笔黑板、作品屏幕、地球的光点有自己的美术，不受 token 约束。
- 叠在场景上的 HTML 界面必须用 token。画在 canvas 上的界面元素（分享卡片、3D 门上的门牌）通过代码里的 `TK` 读取同一套 token，不另起颜色。
- 房主作品自带的皮肤（例如拾光的“轻 / 扭蛋 / 键”）属于作品本身，不随设计系统变化。
